# 매출현황 엑셀 보고서(일일 매출보고) 개발 계획

이 문서는 사용자가 요청한 "판매관리 입력 내용 기반 엑셀 보고자료" 생성 기능에 대한 상세 개발 계획을 담고 있습니다.

## 1. 개요
기존의 단순 CSV/JSON 기반 엑셀 다운로드를 넘어, 첨부된 이미지 양식과 동일한 **"라벤 구독회원 일일 매출보고"** 형태의 정형화된 보고서를 생성합니다.

## 2. 주요 요구사항 반영
- **명칭 통일**: "라벤/리벤" 구분 없이 모두 **"라벤"**으로 통일하여 출력합니다.
- **그룹화**: **날짜**와 **단말기 번호**를 기준으로 데이터를 그룹화합니다.
- **날짜 선택**: 특정 날짜를 선택하여 해당 일자의 보고서를 생성할 수 있도록 합니다.
- **집계 기능**: 단말기별로 데이터를 구분하고, 각 단말기별 합계 금액이 자동으로 취합되도록 구성합니다.
- **가격 반영**: 판매관리 시스템에 입력된 실제 판매 가격을 기준으로 작성합니다.
- **UI 위치**: 시스템 관리자 대시보드(`SystemSalesDashboard`)의 매출현황 필터 영역 하단(엑셀 다운로드 버튼 옆)에 배치합니다.

## 3. 기술적 접근 방식
- **Library**: `exceljs`를 사용하여 복잡한 셀 병합, 테두리, 배경색 스타일링을 적용합니다.
- **Data Handling**: 
    - `sales` 테이블에서 선택된 날짜의 데이터를 조회합니다.
    - `payment_info` JSON 내의 `terminalNo`를 추출하여 그룹핑합니다.
    - `payment_info.items` 정보를 분석하여 한글/영문 버전 및 시리즈별 컬럼에 매핑합니다.
- **File Meta**: 파일명은 `일일매출보고_YYYYMMDD(단말기번호).xlsx` 형태 또는 통합 파일로 생성합니다.

## 4. 작업 단계
### 1단계: 환경 설정
- `exceljs`, `file-saver` 패키지 설치

### 2단계: 엑셀 생성 유틸리티 개발 (`src/utils/excelReportUtils.js`)
- 보고서 헤더(제목, 단말기 정보, 소속 등) 레이아웃 정의
- 데이터 행 생성 및 셀 스타일 지정
- 단말기별 합계 계산 및 병합 로직 구현

### 3단계: UI 연동 (`src/components/SystemSalesDashboard.jsx`)
- 기존 "엑셀 다운로드" 버튼 좌측에 **"매출현황(보고서)"** 버튼 추가
- 날짜 선택을 위한 필터 상태 연동 (이미 존재하는 시작일/종료일 필터 활용 가능성 검토)

### 4단계: 검증
- 실제 입력된 데이터가 양식에 맞게 정렬 및 매핑되는지 확인
- 단말기 번호가 다른 데이터들이 섹션별로 잘 나뉘는지 확인

## 5. 지침 준수
- `agent.md`에 명시된 원칙에 따라 기존 레이아웃이나 기능을 수정하거나 삭제하지 않고 요청된 기능(버튼 추가 및 엑셀 생성)만 정확히 구현합니다.
